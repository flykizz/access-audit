# 欧洲市场合规自查清单

## 文档说明

本清单为 AccessAudit 产品进入欧洲市场所需的合规自查工具，涵盖三大核心认证领域：

1. **ISO 27001** - 信息安全管理体系（14个控制领域）
2. **EN 301 549** - ICT 产品无障碍合规（第9/11/12章，含 WCAG 2.1 AA 及 WCAG 2.2 前瞻性）
3. **GDPR** - 数据保护合规
