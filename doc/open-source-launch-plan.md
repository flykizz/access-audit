## 1. 项目定位

### 1.1 项目名称

| 选项 | 名称 | 优点 | 缺点 |
|------|------|------|------|
| 推荐 | **AccessAudit** | 清晰表达功能，易记 | - |
| 备选 | **A11yAgent** | 行业通用术语 | 可能与其他项目冲突 |
| 备选 | **EAA-Check** | 明确针对 EAA | 限制了应用范围 |

**最终决定：AccessAudit**

### 1.2 项目简介

> AccessAudit 是一个基于 LLM Agent 的自动化无障碍合规检测工具，专注于检测传统静态扫描工具无法覆盖的行为级无障碍问题（如键盘陷阱、焦点管理等），帮助企业快速实现 EAA/WCAG 合规。

### 1.3 核心价值主张

```
传统工具 → 只能检测 25-30% 的无障碍问题（静态代码问题）
AccessAudit → 检测 85%+ 的无障碍问题（静态 + 行为级）

核心差异：
├── 行为级测试（键盘陷阱、焦点管理、Modal 交互）
├── EN 301 549 格式报告生成
├── 一行代码接入
└── BYOLLM（数据不出企业）
```

### 1.4 许可证选择

| 许可证 | 特点 | 适用场景 |
|--------|------|---------|
| **MIT** | 最宽松，允许商业使用和修改 | 推荐：最大化采用率 |
| **MPL-2.0** | 文件级开源，商业友好 | axe-core 使用此许可证 |
| **Apache 2.0** | 专利授权，商业友好 | 企业级项目常用 |

**最终决定：MIT 许可证**

理由：最大化社区采用率，降低企业使用门槛，后续可通过 SaaS 模式商业化。

#!/usr/bin/env node

import { AccessAudit } from '@accessaudit/core';

async function main() {
  const url = process.argv[2];
  if (!url) {
    console.error('Usage: accessaudit <url>');
    process.exit(1);
  }
  
  const auditor = new AccessAudit();
  const results = await auditor.audit(url);
  
  console.log(JSON.stringify(results, null, 2));
}
